# 风格 28：流光渐变

## 概述

柔和彩虹光斑渐变、胶囊控件与可复制的 CSS 色标。

## 适用场景

创意工具、落地页、品牌调色板

## 示例场景

- 示例产品：虹光
- 页面任务：渐变实验室
- 标题：把光，调成你想要的颜色。
- 主要操作：复制渐变 CSS
- 次要操作：浏览预设

## 场景组件

- 预设即所得：三套渐变预设一点就换，预览、色标与代码同步更新。
- 色标可读：每个色标都标了 HEX 值，点一下就能复制。
- 代码就绪：一键复制 background CSS，粘进项目就能用。

## 示例状态

- 紫罗兰：当前
- 落日：预设
- 薄荷：预设

## 布局模式

- 模式：虹光渐变实验室
- 结构：渐变实验室包含头版、大渐变预览、三套预设切换、色标列表与 CSS 导出面板。
- 适配原则：应用视觉语言前，先定义用户真实的主要内容对象、顶层区域、主要操作、信息密度和响应式收拢方式。
- 排版：使用大号圆润无衬线标题、紧凑行高，小字号眉题标注色标与代码。
- 组件：渐变实验室包含头版、大渐变预览、三套预设切换、色标列表与 CSS 导出面板。
- 按钮：使用柔和胶囊控件，复制操作是实心紫色主按钮。
- 图标与媒体：使用一张通栏渐变灵感图与真实的渐变色标、HEX 值，不以装饰性色块填充空间。
- 状态：当前预设、已复制 CSS 与悬停色标。
- 避免：不要把渐变压成单色平涂，也不要加深色厚重面板。

## 视觉语言

- 背景：`#fdfbff`
- 表面：`#ffffff`
- 正文：`#1a1a2e`
- 弱化文字：`#6b7280`
- 主色：`#7c3aed`
- 强调色：`#ec4899`
- 边框：`#e9e4f5`
- 圆角：`24px`
- 面板圆角：`24px`
- 控件圆角：`999px`
- Chip 圆角：`999px`
- 媒体圆角：`24px`
- 几何规则：流光渐变几何搭配大圆角与胶囊控件；避免把所有按钮和 Card 都做成相同的大圆角矩形。
- 阴影：`0 24px 80px rgba(124, 58, 237, .18)`

## 组件细节

- 按钮系统：使用柔和胶囊控件，复制操作是实心紫色主按钮。
- 提示与反馈：必填错误贴近字段显示，完成操作提供可读反馈，所有可见状态都与本地演示数据一致。
- 间距系统：区块间距 32px，预览内边距 20px，色标行 12px。
- 响应式策略：手机上预览在上、色标列表在下，复制按钮保持可见。

## 页面适配指南

- 落地页：使用生动的渐变叙事，呈现实时预览、预设与可复制 CSS。
- 数据看板：仅用于主题与品牌取色器。
- 管理后台：用于主题设置与品牌素材库。
- 表单、Table 与数据：保留可见 Label，使用自定义行内错误与本地确认反馈，不使用浏览器原生校验气泡。
- 移动端：手机上预览在上、列表在下，预设与复制保持可见。
- 不适合：不适合密集数据表，或需要克制企业口吻的页面。

## 使用要点

- 渐变实验室包含头版、大渐变预览、三套预设切换、色标列表与 CSS 导出面板。
- 使用真实的渐变色标、HEX 值与可复制 CSS，不以装饰性色块填充空间。
- 预览、色标与代码保持同步，复制操作用 Toast 确认。
